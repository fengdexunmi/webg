# 十球投篮 · AI 直播间版 (Goofy Hoops Studio)

复刻自 [Goofy Fish - Ten Balls (`goofyfish.com/hoops`)](https://goofyfish.com/hoops)，完整还原极简手绘纸面画风、物理抛物线、蓄力条、空心三分与连中倍率机制，并新增 **AI 角色自动游玩投篮** 与 **直播间小窗（键盘操作模拟 + 弹幕互动 + 语音播报）**。

## 核心亮点

- **原汁原味十球投篮复刻**
  - 完整物理引擎（重力、篮筐碰撞、篮板反弹、篮网缓冲、多球碰撞、手绘摆动地面与程序化 Web Audio 音效）。
  - 空心入网（SWISH）得 3 分，普通进球 2 分；3 连中 ×2 倍积分，6 连中 ×3 倍积分，蓄力条随连中加速。
  - 支持生成并下载 Goofy Fish 风格战绩海报 PNG。
- **多风格 AI 角色自动打球 + 随时手动接管**
  - **校园运动美女 · 林小夏**（默认）：高马尾 + 亮黄发带火柴人造型，节奏轻快稳健，直播梗丰富。
  - **爱投篮的哥哥 · 陈默**：运动发带造型，球场冷面空心射手，极高空心率。
  - **元气体育生 · 阿凯**：出手节奏飞快，热血连击型。
  - **佛系学霸 · 晚晚**：圆框眼镜造型，冷幽默物理系抛物线解说。
  - **我自己玩（手动）**：长按鼠标或 `Space` 蓄力投篮，AI 托管期间按下空格也可一键无缝接管。
- **主播直播小窗 & 机械键盘实况模拟**
  - 可拖拽、三档缩放的 LIVE 直播小窗，实时同步主播动作状态（待机瞄准 / 长按空格专注蓄力 / 空心欢呼 / 失误吐槽）。
  - 内置机械键盘实况显示器（`WASD` / `R` / 发光按压 `SPACE` 空格条），实时显示按压毫秒数、蓄力百分比并触发机械轴体音效。
  - 支持点击小窗 `📷` 按钮或直接**拖拽真人照片**到直播小窗替换主播画面；也支持在 `assets/` 目录放置多表情帧自动切换：
    - `assets/campus_girl_idle.png`（待机）
    - `assets/campus_girl_press.png`（长按空格蓄力）
    - `assets/campus_girl_cheer.png`（进球欢呼）
    - `assets/campus_girl_miss.png`（打铁表情）
- **直播间配套功能**
  - **自动连播**：每轮结束后 3 秒倒计时自动开启下一局，适合 OBS 挂机直播。
  - **弹幕与聊天室**：支持开启飘屏弹幕、观众实时反应，输入关键词（如“加油”“换哥哥”“换小夏”）可与主播实时互动。
  - **OBS 纯净模式**：一键隐藏顶部控制条，保留干净的游戏画布与直播小窗。
  - **中文语音播报（可选）**：基于浏览器 Web Speech API 朗读主播解说。

## 本地运行

```bash
python3 -m http.server 4173
```

然后在浏览器访问 `http://localhost:4173`。
