1. 纸面与手绘墨线视觉 Token

  • 白昼点阵纸 (`#FFFFFF`)：24px 间距浅灰圆点阵，营造手账方格本呼吸感。
  • 黄昏暖杏纸 (`#FFF9F0`)：`17:00–19:00` 自动叠入夕阳暖调与斜长投影。
  • 静谧熄灯纸 (`#131722`)：`23:00–06:30` 转为深蓝灰点阵 + 暖色小夜灯局部照明。
  • 微抖手绘墨线 (`#141414`)：所有家具、黑板、篮筐、餐盘、小猫均通过 `WOBBLE` 双正弦函数在每帧产生 0.35px 微幅手绘生命感。

2. 三层正交遮挡合成规范

  • Layer 1 (`#bgSketchCanvas`)：绘制地面线、墙面窗景、黑板、书架、篮架等处于人物身后的 2D 手绘元素。
  • Layer 2 (`#avatar3dCanvas`)：Three.js 透明 WebGL 正交相机，驱动 `alexis.glb` 站立/落座/慢跑/投篮 + `ShadowMaterial` 柔和接触阴影。
  • Layer 3 (`#fgSketchCanvas`)：绘制课桌前挡板（自然遮住坐姿大腿）、手持 2D 篮球/书本/咖啡杯、小橘猫与头顶碎碎念气泡。

3. 3D 骨骼动作状态机接口

  • `sit_write` / `sit_type`：骨盆落于椅面 `Y=-42`，屈膝踩地，右手沿桌面轨迹微幅书写或双手敲击键盘。
  • `hoops_play`：直接挂载 `webg` 十球投篮物理模块，支持 Auto 练球与玩家空格键无缝接管。
  • `jog_loop` & `pet_cat`：正弦步态摆臂慢跑，点击前景手绘小猫触发转身下蹲摸头交互。
  • `stand_sing`：右手扶复古手绘立麦，身体与头部随节拍轻柔摆动。
